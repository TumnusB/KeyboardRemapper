# KeyboardRemapper

A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod for [Resonite](https://resonite.com/) 
that lets you rebind both Keyboard and Mouse Inputs, any changes will not update until you restart your game

Please make an Issue if you find a Bug, as I am not a Desktop user and was made for one who is still testing this mod.

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
1. Place [KeyboardRemapper.dll](https://github.com/TumnusB/KeyboardRemapper/releases/latest/download/KeyboardRemapper.dll) into your `rml_mods` folder. 
This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default install. You can create it if it's missing, or if you launch the game once with ResoniteModLoader installed it will create this folder for you.
1. Start the game. If you want to verify that the mod is working you can check your Resonite logs.

## Optional 
This mod uses the config options from ResoniteModLoader as such if you don't want to manually edit the JSON file then I advise you look use this mod
[ResoniteModSettings](https://github.com/badhaloninja/ResoniteModSettings)
